## Goal
Provide financial analytics and insights.

## Features to Build

### 1. Monthly Summary
Display:
- Total Income for the current month
- Total Expenses for the current month
- Net Savings/Loss for the current month

### 2. Category-wise Spending
Display:
- A breakdown of spending by category for the current month
- Show each category and the total amount spent in it

## Success Criteria
✅ Can view a monthly summary of income, expenses, and net savings/loss.
✅ Can view spending broken down by category for the current month.
✅ Accurate calculations for all analytics.
✅ Beautiful colored output.

## Goal
Provide tools for managing financial data, including export and reset options.

## Features to Build

### 1. Export Data
Allow users to export all transaction and budget data to a CSV file.
- Ask for a filename.
- Export transactions and budgets in a readable CSV format.

### 2. Reset Data
Provide an option to clear all transaction and budget data.
- Warn the user before proceeding with data deletion.
- Delete the contents of `transactions.txt` and `budgets.txt`.

## Success Criteria
✅ Can export transaction and budget data to a specified CSV file.
✅ Can reset all transaction and budget data after user confirmation.
✅ Data integrity is maintained during export.
✅ User is adequately warned before irreversible data deletion.
✅ Beautiful colored output.

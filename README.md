# 🌐 Gemini CLI & Spec Kit Projects

This repository contains a collection of my experiments, tools, and mini-projects built using Gemini CLI and Spec Kit.
The goal of this repo is to document my learning, showcase hands-on implementations, and build useful utilities using Google’s Gemini ecosystem.

## 📌 What’s Included

Gemini CLI Projects – AI-powered command-line tools, automation scripts, and creative experiments.

Spec Kit Projects – Structured AI workflows, schema-based apps, and generation pipelines.

Hybrid Tools – Projects combining both Gemini CLI + UI frameworks like Streamlit.

Personal Utilities – Custom tools such as personal finance trackers, task managers, and more.

## 🔥 Why This Repo Exists

To track my journey of working with agentic AI tools.

To build a centralized space for all Gemini CLI + Spec Kit experiments.

To share working demos, ideas, and reusable components.

To document how AI tools can be used to build fast prototypes and real-world applications.

## 🚀 Tech Stack

Gemini CLI – AI-assisted development, workflows, automation

Spec Kit – Schema-based AI app building

Python, Streamlit, CLI tools

Additional libraries depending on the project

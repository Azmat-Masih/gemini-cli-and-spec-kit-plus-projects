## Goal
Implement category-based budgeting with alerts.

## Features to Build

### 1. Set Budget
Flow:
1. Ask for category (from predefined list, e.g., Food, Transport, etc.)
2. Ask for budget amount for the current month (validate: positive number)
3. Save to budgets.txt

### 2. View Budgets
Display:
- Show all set budgets in a Rich table
- Columns: Category, Budgeted Amount, Spent Amount (this month), Remaining Amount, Status (e.g., "Under Budget", "Over Budget")
- Color: Green for under budget, Red for over budget

## Success Criteria
✅ Can set a budget for a category.
✅ Can view current budgets with spending and remaining amounts.
✅ Accurate budget calculations.
✅ Beautiful colored output.
